# placement_preparation_dashboard
Placement Preparation Dashboard

A web-based application designed to provide students with a centralized platform for preparing for campus placements.

The Placement Preparation Dashboard brings multiple placement-preparation activities together in one system. Students can track company applications, monitor coding progress, take aptitude and technical quizzes, view their performance, identify weak subjects, manage resumes, and keep track of important reminders.

Key Features

- Student Registration and Login
- Company and Application Tracker
- Coding Progress Tracker
- Aptitude and Technical Quiz Module
- Automatic Quiz Evaluation
- Quiz History
- Performance Analytics
- Weak Subject Detection
- Resume Upload and Download
- Placement Preparation Reminders
- Admin Dashboard and Statistics

Technology Stack

- Frontend: HTML, CSS
- Backend: Python, Flask
- Database: PostgreSQL
- Development Environment: Visual Studio Code
- Database Management: pgAdmin

Purpose

The main purpose of this project is to simplify and organize the placement preparation process by providing students with a single platform to manage their preparation activities and monitor their progress.

Project Type

Web Application / Academic Mini Project
